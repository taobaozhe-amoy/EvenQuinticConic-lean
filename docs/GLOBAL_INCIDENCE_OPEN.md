# 全局关联概形中的实际有理开集

本阶段补上此前局部模型与全局概形之间的连接。结论仍以实际矩阵网、公共非零点和行列式 Jacobian 条件为输入，不是从原题的 even theta 条件直接得到实连通性。

## 端点的精确输入输出

`exists_nonempty_rational_globalIncidenceOpen_of_common_point` 接收：

- 无限域 `K`，且 `2 ≠ 0`；
- 三个实际对称 `5 × 5` 矩阵 `Mᵢ`；
- 非零公共各向同性向量 `P`，即每个 `PᵀMᵢP=0`；
- 实际行列式多项式的 Jacobian 条件：对非零 `t ∈ K³`，若 `det(Σ tᵢMᵢ)=0`，则某个实际偏导在 `t` 处非零。

它内部构造第一列为 `P` 的可逆矩阵 `B`，并在变换后的网 `BᵀMᵢB` 上选出 `k,p`，得到实际全局概形 `Z` 的开集 `U`，满足：

1. `U` 非空，且 `U.toScheme` 为整概形；
2. `U.toScheme ≅ Spec S`，其中 `S` 是实际 Segre 方程商环在指定三次子式处的局部化；
3. 这个概形同构与 `U → Z → Spec K` 的原结构态射相容；
4. `S` 是整环，且 `FractionRing S ≃ₐ[K] FractionRing (K[u,v,w])`。

非零子式、非空性、整性、开图同构、保持基域和函数域同构都不是端点的输入。Jacobian 条件按 `K` 点表述；这里不把它反向解释为任意域上几何光滑性的完整刻画。

## 全局对象如何定义

令 `z_(i,a)=tᵢyₐ`，其中 `i∈Fin 3`、`a∈Fin 4`。在实际 `Proj K[z_(i,a)]` 中使用下列齐次方程：

- 所有 `2 × 2` Segre 子式；
- 线性式 `L=Σ Mᵢ(a+1,0) z_(i,a)`；
- 对每个 `k`，二次式 `Qₖ=Σ Mᵢ(a+1,b+1) z_(i,a)z_(k,b)`。

代入 Segre 坐标后，它们分别成为秩一关系、`Σ tᵢℓᵢ(y)=0` 和 `tₖ Σ tᵢrᵢ(y)=0`。由于参数向量非零，三个二次方程恢复所需的第二个关联方程。

`GlobalIncidenceScheme` 定义为这个齐次闭集的**约化闭子概形**，带有实际结构层和闭浸入。场值坐标解的精确对应单独证明；后面的概形同构不依赖“场值点相同所以概形相同”的推理，也未把尚未构造的乘积概形同构当作假设。

## 局部比较及根性

在 `z_(k,p)≠0` 的实际射影标准开集，先证明真实度零齐次局部化等于 `K[z]/(z_(k,p)−1)`，其中 `F/z_(k,p)^d` 映到 `F` 的商类。

全部 Segre 子式连同归一化方程的商环，明确同构于两个参数变量和三个 `y` 仿射变量的多项式环。加入全部关联方程后，所得理想**恰好**是两个原始关联方程生成的理想；这是普通理想与完整商环的比较，保留可能的幂零结构。

全局三次式 `δ_(k,i,j)(z)=Δᵢⱼ(z_(k,*))` 拉回为 `tₖ³Δᵢⱼ(y)`。规范次序 `i=k.succAbove 0`、`j=k.succAbove 1` 下，它就是局部消元所用的子式。

关键顺序是：

1. 在实际射影坐标图中反演这个子式；
2. 证明局部化与商环交换，并连接到已证的显式消元同构；
3. 从子式非零证明局部商环为整环，因此局部方程理想是根理想；
4. 计算实际射影图态射下所有齐次方程的逆像，再用实际闭浸入及理想层比较构造开浸入。

没有假设未局部化的全局或仿射方程理想为根理想。最终开图的像严格等于

`U = Z ∩ D₊(z_(k,p)) ∩ D₊(δ_(k,i,j))`。

## 仍未得到的结论

后续 [实际投影支配性结果](INCIDENCE_DOMINANCE.md) 已在几何 Jacobian 条件下证明这个具体开集的参数投影支配 `ℙ²`。原本只检查 `K` 点的较弱假设仍是本文件旧端点的输入，未被直接升级。尚未证明这个开集在整个 `Z` 中稠密或整个 `Z` 不可约；此前在 `ℙ³` 中的稠密性不能代替这些结论。

未证明全局关联模型与题目指定圆锥丛之间的双有理比较；矩阵网与公共实点仍是输入，尚未从原题的偶 theta 条件产生。指定判别覆盖、theta 对应和实基变换、Brauer/二次型/零循环输入以及最终实连通性仍未全部形式化。

因此本阶段解决了真实的局部到全局开图缺口，但不构成原题的完整证明。

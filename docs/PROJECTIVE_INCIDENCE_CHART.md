# 实际射影关联局部图与三变量函数域

本阶段补上此前仿射锥局部图的射影坐标连接。这里仍从一个实际对称矩阵网及其公共点开始，尚未从原圆锥丛和 even theta 条件产生这些输入。

## 精确输入

`exists_rational_projectiveIncidenceChart_of_common_point` 接收：

- 无限域 `K`，其中 `2 ≠ 0`；
- 三个实际对称 `5 × 5` 矩阵 `Mᵢ`；
- 非零向量 `P`，满足每个 `PᵀMᵢP = 0`；
- 实际行列式多项式的 Jacobian 条件：每个非零 `t`，若 `det(Σ tᵢMᵢ)=0`，则至少一个实际偏导在 `t` 处非零。

不输入坐标变换、子式非零、局部图非空、整性或函数域有理性。上述 Jacobian 条件按 `K` 点写出；本接口没有把它反向宣称为几何光滑性的完整刻画。

## 实际对象与映射

先内部构造可逆矩阵 `B`，使第一列为 `P`。在变换后的实际矩阵网中抽取线性行 `ℓᵢ` 和二次行 `rᵢ`，并令

`Δᵢⱼ = ℓᵢ rⱼ − ℓⱼ rᵢ`。

此前的代数证明给出非零的实际取值 `Δᵢⱼ(y)`，进而选择 `yₚ ≠ 0`。本阶段使用真正的度零齐次局部化

`Rₚ = (K[y₀,y₁,y₂,y₃]_(yₚ))₀`。

`ProjectiveThreeChartRing.lean` 构造 `Rₚ ≃ₐ[K] K[u,v,w]`，其正向映射令 `yₚ=1`，逆向把三个仿射变量送到 `y_q/yₚ`。两个复合恒等式均由实际环映射证明，常数映射也明确保持。

在 `Rₚ` 中，关联方程的系数分别为 `ℓᵢ/yₚ` 和 `rᵢ/yₚ²`。它们的子式是 `δ=Δᵢⱼ/yₚ³`。局部化后，在第三个关联参数归一为一的坐标图中，使用实际商环

`A = Rₚ[1/δ][s,t] / (aₓ s + aᵧ t + a_z, bₓ s + bᵧ t + b_z)`。

消元产生实际代数同构 `A ≃ Rₚ[1/δ]`。结合 mathlib 的真正 `Proj` 标准开集同构，得到

`Spec A ≅ D₊(yₚ) ∩ D₊(Δᵢⱼ) ⊂ Proj K[y₀,y₁,y₂,y₃]`。

另外证明局部同构后接开集包含正是系数映射诱导的原投影，并与实际 `ℙ³ → Spec K` 结构态射相容。

非空性由原来的取值见证推导，整性由实际环嵌入推导。`ProjectiveThreeDensity.lean` 从齐次零素理想构造泛点，证明实际射影三空间不可约，因此此非空开集在 `ℙ³` 中稠密。这里不把它宣称为已在尚未构造的全局关联簇中稠密。`IncidenceFunctionField.lean` 与 `NetRationalIncidenceChart.lean` 继续组合得到

`FractionRing A ≃ₐ[K] FractionRing (K[u,v,w])`。

因此这里的函数域同构保持 `K`，不是任意抽象域同构。另从实际系数环到泛点茎的结构映射构造基域作用，给出实际仿射概形泛点茎与这个有理函数域的 `K`-代数同构。

`IncidenceDehomogenization.lean` 独立记录实际多项式代换、齐次次数、精确缩放公式及三变量取值见证，避免用四维仿射锥的分式域代替三维射影空间的函数域。
